# BakeryHub

Plataforma SaaS para notificação de produção em tempo real.

O objetivo do BakeryHub é conectar estabelecimentos e consumidores, permitindo que clientes recebam notificações quando produtos estiverem próximos de ficar prontos.

Este projeto está sendo desenvolvido como laboratório prático para estudo e demonstração de arquiteturas modernas utilizando .NET, React, MAUI, RabbitMQ, Docker, Azure e outras tecnologias do ecossistema Microsoft.

## Status

🚧 Em desenvolvimento

Atualmente o projeto encontra-se em fase de planejamento e definição da arquitetura.

## Objetivos do Projeto

- Construir uma aplicação full stack moderna
- Aplicar conceitos de Clean Architecture
- Utilizar mensageria baseada em eventos
- Implementar autenticação e autorização com JWT
- Trabalhar com containers utilizando Docker
- Realizar deploy na Azure
- Desenvolver aplicações Web e Mobile utilizando o mesmo backend
